## Context

Teams were spending too long hunting for answers across documents. The platform gives each organisation (tenant) a private knowledge base and a chatbot that answers from it - and only from it.

## The pipeline

1. **Ingest** - content is collected per tenant (documents and crawled web pages).
2. **Parse and chunk** - content is cleaned and split into retrieval-sized chunks.
3. **Embed** - each chunk is embedded and stored with its tenant's vectors.
4. **Retrieve** - at question time, the top matching chunks for that tenant are found by semantic search.
5. **Answer** - the model answers from the retrieved chunks and returns links to its sources.

## Tenant isolation

Isolation is a security boundary, not a feature: a question from one tenant must never retrieve another tenant's content. Retrieval is always scoped to the asking tenant, and tenants are identified by their own API keys, which also drive usage tracking for plan limits.
